# Windows11Customization
A Windows PowerShell script to customize your Work or School windows computer without needing admin rights. 
Copy and paste the code into windows PowerShell for it to work (DOES NOT WORK IN WINDOWS COMMAND PROMPT, SOME SCHOOLS HAVE COMMAND PROMPT BLOCKED) I am working on a mac version right now. I update my GitHub page everytime i update the code. Thanks for using my script.
